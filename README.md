## How I operate

- **Latency is the enemy of trust.** Delay creates doubt; every millisecond removed is confidence restored.
- **URL > Store.** State you can't share via a link shouldn't exist.
- **Server > Client.** Ship HTML, not JSON — the critical rendering path is the product.
- **WET > DRY.** The wrong abstraction costs more than a little duplication.
- **The spec is the artifact.** When agents write the code, the precise description is the engineering.
- **"Done" requires a receipt.** No diff, no test run, no artifact — no done. Same bar for humans and machines.
- **Fix the loop, not the model.** A real agent run has a goal, boundary, tools, artifacts, and receipts — miss one and it's a wish.
